# finmath-distill benchmark

Набор из четырёх JSONL-датасетов финансовой математики (`finmath-distill`) и
скрипт `benchmark_model.py` для прогонки LLM-эндпоинтов (OpenAI-compatible
`/chat/completions`) по этим датасетам с автоматической проверкой ответов.

## Датасеты

Файлы лежат в каталоге `datasets/`:

| Файл | Тип | Задач | Формат ответа |
|------|-----|-------|---------------|
| `finmath-distill-enum.jsonl` | `enum` | 4 906 | перечисление элементов (список) |
| `finmath-distill-formula.jsonl` | `formula` | 3 948 | формула (LaTeX) |
| `finmath-distill-math.jsonl` | `math` | 4 093 | число, `Answer: <number>` |
| `finmath-distill-yesno.jsonl` | `yesno` | 13 204 | да/нет |

Каждая строка — отдельный JSON-объект со схемой:

- `source` — всегда `"finmath-distill"`;
- `messages` — пара user/assistant: вопрос и эталонный ответ;
- `id` — вида `section-<n>-<n>-dataset-<type>:<index>`;
- `type` — тип задачи, совпадает с суффиксом файла;
- `answer` — только в `math` (числовой эталонный ответ).

Квик-взгляд на датасет (файлы большие, целиком не читать):

```bash
head -c 2000 datasets/finmath-distill-enum.jsonl
```

Особенность: в `math` переводы строк внутри `messages[].content` сохранены как
литеральные двухсимвольные последовательности `\n` (двойное экранирование).
Скрипт разворачивает их перед отправкой, сохраняя настоящие LaTeX-команды
вроде `\nu` и `\neq`.

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Зависимости: `aiohttp`, `sympy`, `numpy`.

## Запуск бенчмарка

```bash
python3 benchmark_model.py --host <host[:port]> --token <token> --model <model> [опции]
```

Обязательные именованные аргументы (порядок не важен):

- `--host` — эндпоинт, например `localhost:8000` или
  `http://host:8000/v1` (к URL автоматически добавляется `/v1`, если его нет);
- `--token` — access token, отправляется как `Authorization: Bearer <token>`;
- `--model` — имя модели, передаваемое в запросе.

### Опции

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `-c, --concurrency N` | `1` | число параллельных запросов |
| `-d, --datasets LIST` | `all` | датасеты через запятую: `enum,formula,math,yesno` |
| `-n, --limit N` | `1000` | максимум задач на датасет (случайная выборка, если меньше размера) |
| `--seed S` | — | seed для случайной выборки |
| `--timeout SECONDS` | `120` | таймаут одного запроса |
| `--max-tokens N` | `2048` | лимит токенов на ответ модели |
| `-v, --verbose` | — | печатать все расхождения, а не только первые примеры |

### Примеры

```bash
# Полный прогон по всем датасетам
python3 benchmark_model.py --host localhost:8000 --token "$TOKEN" --model my-model -c 8

# Быстрая прикидка: 200 случайных задач на датасет с фиксированным seed
python3 benchmark_model.py --host localhost:8000 --token "$TOKEN" --model my-model -n 200 --seed 42 -c 8

# Только enum и math; порядок именованных аргументов не важен
python3 benchmark_model.py --model my-model --host localhost:8000 --token "$TOKEN" -d enum,math
```

### Как оцениваются ответы

- **enum** — сравнение множеств выбранных элементов без учёта порядка;
  устойчиво к регистру, пунктуации, лишним пробелам, маркерам списков и
  вариантам перечисления («a, b and c» / «a, b, c»). Ответ модели может быть
  отформатированным: markdown-буллеты и нумерация (`-`, `*`, `1.`, `1)`),
  жирный текст, галочки/кресты (✅/❌ — отмеченные крестом варианты
  отбрасываются), заголовки вида «**Correct selections:**» и завершающий
  комментарий отделяются от самого перечня. «All of the above» / «none of
  the above» / «all except X» разворачиваются в явный список опций из
  условия; для переформулированных пунктов есть fuzzy-фолбэк (пословное
  покрытие строк списка), который не срабатывает на вырожденных эталонах
  (однословные и взаимовложенные пункты), чтобы не пропускать лишние или
  недостающие варианты.
- **formula** — символическое сравнение через sympy: LaTeX переводится в
  sympy-выражение, затем проверяется численной подстановкой случайных
  значений символов и `simplify`. Посимвольного совпадения не требуется.
  Дополнительно допускаются: ответ без префикса «X =» (сравнивается только
  правая часть), синонимичные имена переменных (`R_t` вместо
  `\text{Revenue}_t`, `Net Working Capital_before` вместо `NWC_before`) —
  через поиск биекции свободных символов, при которой формулы совпадают, а
  каждая пара имён правдоподобно означает одно и то же (совпадение /
  подстрока / акроним / короткая подпоследовательность). Также нормально
  обрабатываются знаки процента (`\times 100\%` ≡ `\times 100` — маркер
  единицы измерения; `15\%` ≡ `0.15`; `\%` внутри `\text{...}` — часть
  оформления) и индексы у команд (`\beta_i` — один символ `beta_i`).
  Перестановка операндов (`-`, `/`), другой оператор или шаблонные имена
  (`X = A - B`) по-прежнему не засчитываются.
- **math** — из ответа извлекается финальный `Answer: <number>` (или последнее
  число в тексте) и сравнивается с эталоном с относительным допуском ~0.5 %;
  поддерживаются знаки `%` и эталоны из нескольких значений.
- **yesno** — извлечение да/нет без учёта регистра и пробелов.

Запросы с временной ошибкой (429/5xx, сетевые сбои, таймаут) ретраятся до
3 раз; ошибки аутентификации и некорректного запроса (400/401/403/404)
немедленно прерывают весь прогон.

Вместе с вопросом отправляется датасет-специфичный системный промпт: для
`enum` — строгий формат перечисления, для `formula` — одна строка LaTeX без
комментариев и с теми же именами переменных, что использованы в вопросе.

По завершении печатается таблица `correct/total`, accuracy и число ошибок
по каждому датасету и итог (TOTAL), затем — примеры расхождений и ошибок.
